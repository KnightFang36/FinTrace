# docs instructions

## Purpose
Maintain project architecture, schemas, dataset constraints, roadmap and feature specifications.

## Inputs
Approved scope, publisher facts, implemented behaviour and explicit design decisions.

## Outputs
Accurate Markdown contracts that distinguish planned interfaces from available functionality.

## Functionality
architecture.md describes dependencies; data_contracts.md defines records; dataset.md records source limitations; roadmap.md defines implementation phases; features holds per-feature contracts.

## Constraints
Keep links relative and valid. Update status when implementation changes. No performance claims without measured evidence. Preserve non-ML scope.

# docs/features instructions

## Purpose
Provide one authoritative contract directory per feature.

## Inputs
Feature scope, data availability, proposed interfaces, workflow and edge cases.

## Outputs
Feature README.md plus AGENTS.md with input/output/functionality responsibilities.

## Functionality
Maintain the linked feature inventory in the root README. Each feature must specify errors, acceptance criteria and gating on missing source information.

## Constraints
Document every new feature before presenting it as implemented. Do not treat label-based evaluation or optional missing context as detector input.
